# 任务完成通知

读取每个会话本来就在发布的会话状态，在系统通知区域报告两类时刻：

- 会话停止运行——这一轮已结束；
- 会话开始等你回复——提问、计划审阅，或等待授权。

子代理会话保持安静，只有你自己驱动的会话才发通知。

## 你会看到什么

Harness 窗口内不画任何东西。通知出现在操作系统的通知区域——Windows 上就是屏幕右下角——所以无论 Harness 在前台还是被别的窗口挡住，你都能收到。

- “运行已结束”——一轮运行停止了，正文是会话名；
- “等待你的回答”——会话向你提了问题；
- “等待你的确认”——会话正卡在一个需要你拍板的决定上。

点击通知会把窗口带到前台并打开该会话。所有通知共用一个 tag，因此应用的最新状态会替换上一条，而不是越堆越多。

通知使用操作系统自带的提示音；插件不再额外合成声音，也不带任何音频文件。

## 权限

页面需要通知权限。桌面应用会直接授予、不弹询问；普通浏览器在第一次点击时询问一次，之后不再打扰。

## 范围

通知只读取客户端本来就维护的会话状态，不增加 Host 侧工作、存储或网络请求。这份快照只说明会话是否在运行、并不说明这一轮成功与否，所以文案只报告“运行已结束”，不谎称成功。Harness 关闭期间结束的任务也无法补报。
